# CareerMate — Multi-Sector Production UI Demo

Interactive HTML/CSS/JavaScript frontend prototype for an AI-powered recruitment platform.

## Candidate flows
- Landing, login, signup, multi-sector onboarding
- Job discovery across Technology, Marketing, Sales, Finance, HR, Design, Operations, Customer Support, Healthcare, Education and other fields
- Job detail with explainable AI match
- Full apply flow: CV choice, screening questions, supporting info, consent, submission confirmation
- Saved jobs
- CV/resume upload + multi-version manager + AI review
- Application tracker
- AI Career Coach
- Messages, notifications, professional profile, privacy/settings

## Employer flows
- Employer setup and dashboard
- Multi-sector job posting with category-specific guidance
- Manage jobs
- Candidate review and candidate detail
- Hiring pipeline
- Messages
- Hiring analytics
- Company profile

## Admin flows
- Platform overview
- User management
- Job moderation
- Reports and safety queue

## Run
Open `index.html` in a modern browser. No build step is required.

This is a frontend prototype with demo data. Production deployment still needs a backend, database, authentication, file storage, AI service integration, email/notification infrastructure, moderation controls and security hardening.
